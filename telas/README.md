# Telas atuais — Cidade Dorme

Imagens em [desktop](desktop/) e [mobile](mobile/), incluindo as variações de cada tela. Capturas da interface atual com dados de exemplo.

Todas compartilham cabeçalho com cenário de dia/noite e rodapé. Dentro da sala, há código e link de convite para copiar.

A seleção de papéis é feita pelo administrador em quantidades; cada jogador recebe o seu por sorteio. A conversa acontece em chamada externa.

Expulsar e fechar sala pedem confirmação nativa do navegador, descrita aqui porque não aparece nas screenshots da página.
